# E-CELL – SRM Application-Based Virtual Electrochemistry Lab

## Run
pip install -r requirements.txt
streamlit run app.py

## Streamlit deployment
Upload this folder to GitHub and deploy `app.py` using Streamlit Community Cloud.

## Main modules
- Virtual Galvanic Cell
- Nernst Equation
- Gibbs Free Energy
- Theory
- Quiz
- Application-Based Learning Report
